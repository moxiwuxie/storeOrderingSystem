# 接口文档

- Base URL：`http://127.0.0.1:8000`（生产为 `https://your-domain.com`）
- 在线调试：启动后访问 `/docs`（Swagger UI）
- 所有响应统一结构：

```json
{ "code": 0, "msg": "ok", "data": {} }
```

`code` 为 `0` 表示成功，`1` 表示业务失败，失败原因在 `msg`。

- 鉴权：需登录的接口在请求头带 `Authorization: Bearer <token>`
  - 用户端 token 由 `/api/auth/wechat`、`/api/auth/alipay`、`/api/auth/h5` 返回
  - 管理端 token 由 `/api/admin/login` 返回，两者不可混用

> **多端说明**：同一套接口同时服务微信小程序与 H5 点单页（浏览器 / 支付宝内打开）。
> 用户登录统一走 `/api/auth/*`，支付统一走 `/api/payment/prepay` 并用 `source` 区分来源端。

## 一、登录模块

### POST /api/auth/wechat — 微信授权登录

```json
// 请求
{ "code": "wx.login 返回的 code", "nickname": "可选", "avatar": "可选" }
// 响应 data
{ "token": "jwt", "user_id": 1, "nickname": "微信用户", "avatar": "" }
```

### POST /api/auth/alipay — 支付宝扫码登录

```json
// 请求
{ "auth_code": "支付宝授权码", "nickname": "可选", "avatar": "可选" }
```

### POST /api/auth/h5 — H5 免注册登录（浏览器 / 支付宝内打开）

H5 端无法静默获取微信 code，故提供免注册登录：以「支付宝授权码 > 手机号 > 设备标识」的优先级识别顾客，命中即复用同一账号，否则创建新用户。设备标识由前端生成并持久化在 `localStorage`，保证同一浏览器再次进入仍是同一账号、能看到历史订单。

```json
// 请求
{
  "device_id": "前端生成的设备标识，至少 8 位，必填",
  "auth_code": "可选，支付宝内打开时传授权码，可自动绑定支付宝身份",
  "phone": "可选，已绑手机号可用它找回账号",
  "nickname": "可选",
  "avatar": "可选"
}
// 响应 data
{ "token": "jwt", "user_id": 3, "nickname": "顾客", "avatar": "" }
```

> 同一 `device_id` 重复调用返回同一 `user_id`；不同设备、不同手机号则为不同账号。

### GET /api/auth/profile — 当前用户信息（需登录）

`data`: `{ user_id, nickname, avatar, phone, bind_wechat, bind_alipay }`

## 二、商品模块（免登录）

### GET /api/products/categories

分类 + 在售商品，用于点单页左右联动。

```json
// data
[{
  "id": 1, "name": "招牌饮品", "sort": 1,
  "products": [{
    "id": 1, "name": "招牌珍珠奶茶", "description": "...", "image": "",
    "price": 16.0, "stock": 130, "unit": "杯", "status": true,
    "specs": [ { "id": 1, "name": "中杯 常温", "price": 16.0, "stock": 50 } ]
  }]
}]
```

> 有规格的商品：`price` 取最低规格价，`stock` 取规格库存合计。

### GET /api/products?category_id=&keyword=

商品列表，支持分类与名称模糊筛选。

### GET /api/products/{product_id}

商品详情，结构同列表中的单个商品。

## 三、购物车模块（需登录）

### GET /api/cart

```json
// data
{
  "items": [{
    "id": 10, "product_id": 1, "spec_id": 1,
    "name": "招牌珍珠奶茶", "spec_name": "中杯 常温", "image": "",
    "price": 16.0, "quantity": 2, "stock": 50, "subtotal": 32.0
  }],
  "total_quantity": 2, "total_amount": 32.0
}
```

### POST /api/cart — 加入购物车

```json
{ "product_id": 1, "spec_id": 1, "quantity": 1 }
```

同一商品同一规格重复加购会累加数量；超出库存返回 `code=1`，`msg="库存不足，当前仅剩 N 杯"`。返回最新购物车。

### PUT /api/cart/{item_id} — 修改数量

```json
{ "quantity": 3 }
```

### DELETE /api/cart/{item_id} — 删除单项

### DELETE /api/cart — 清空购物车

## 四、下单与订单模块（需登录）

### POST /api/orders — 提交订单

```json
{ "remark": "少冰", "table_no": "A12" }
```

从购物车生成订单：事务内逐项校验库存 → 扣减 → 写入明细 → 清空购物车。
返回订单对象；库存不足返回 `code=1`，`msg="「香酥鸡米花」库存不足，仅剩 3 份"`。

### GET /api/orders?status= — 我的订单列表

`status` 可选：`0` 待支付、`1` 已支付、`2` 已完成、`3` 已取消。

```json
// data[i]
{
  "id": 1, "order_no": "SO202610111530001234",
  "total_amount": 32.0, "pay_amount": 32.0,
  "status": 0, "status_text": "待支付",
  "pay_type": "", "table_no": "A12", "remark": "少冰",
  "pay_time": null, "created_at": "2026-10-11T15:30:00",
  "items": [{ "product_id": 1, "product_name": "招牌珍珠奶茶", "spec_name": "中杯 常温",
              "price": 16.0, "quantity": 2, "subtotal": 32.0 }]
}
```

### GET /api/orders/{order_no} — 订单详情

仅能查询自己的订单，越权返回 404。

### POST /api/orders/{order_no}/cancel — 取消订单

仅 `待支付` 状态可取消，取消后自动回滚库存。

## 五、支付模块（需登录）

### POST /api/payment/prepay — 发起支付

```json
{ "order_no": "SO202610111530001234", "pay_type": "wechat", "source": "miniprogram" }
```

| 参数 | 说明 |
|---|---|
| `order_no` | 订单编号 |
| `pay_type` | `wechat` 微信 / `alipay` 支付宝 |
| `source` | `miniprogram`（默认）小程序端 / `h5` 浏览器或支付宝内 H5 端 |

返回的 `pay_params` 形态由「渠道 × 来源端」决定，前端按 `pay_params.mode` 处理：

| pay_type | source | `mode` | `pay_params` 内容 | 前端处理 |
|---|---|---|---|---|
| wechat | miniprogram | `jsapi` | 微信支付 JSAPI 参数 | `wx.requestPayment(...)` |
| wechat | h5 | `h5_redirect` | `{ "h5_url": "..." }` | `location.href = h5_url` |
| alipay | miniprogram | `order_str` | `{ "orderStr": "..." }` | `my.tradePay({ orderStr })` |
| alipay | h5 | `h5_form` | `{ "form_html": "<form ...>" }` | 注入并提交表单跳转支付宝 |

```json
// data（以小程序微信支付为例，PAY_MODE=real 时返回真实支付参数）
{
  "order_no": "SO...", "pay_type": "wechat", "mock": false, "paid": false,
  "pay_params": { "mode": "jsapi", "timeStamp": "...", "nonceStr": "...",
                  "package": "prepay_id=...", "signType": "RSA", "paySign": "..." }
}
```

`PAY_MODE=mock`（本地默认）时 `mock=true, paid=true`，订单立即置为已支付；H5 端同样返回对应的 `mode`，只是地址指向 mock 域名，便于前端走通跳转逻辑。

### POST /api/payment/wechat/notify — 微信支付回调（渠道调用，无需鉴权）

接收成功返回 `{"code":"SUCCESS","message":"成功"}`；处理逻辑为幂等地把待支付订单改为已支付并写入交易号。

### POST /api/payment/alipay/notify — 支付宝支付回调

成功返回字符串 `success`。

## 六、管理端（商家）

### POST /api/admin/login

```json
{ "username": "admin", "password": "admin123" }
// data: { "token": "jwt", "real_name": "店长" }
```

以下接口均需 `Authorization: Bearer <管理员token>`。

### 分类

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/categories` | 分类列表（含商品数）|
| POST | `/api/admin/categories` | `{ name, sort, status }` |
| PUT | `/api/admin/categories/{id}` | 同上 |
| DELETE | `/api/admin/categories/{id}` | 分类下有商品时禁止删除 |

### 商品

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/products?category_id=&keyword=` | 商品列表（含规格）|
| POST | `/api/admin/products` | 新增商品（可带 `specs`）|
| PUT | `/api/admin/products/{id}` | 编辑商品与规格 |
| PUT | `/api/admin/products/{id}/status?status=true` | 上下架 |
| PUT | `/api/admin/products/{id}/stock?spec_id=` | 库存维护 |
| DELETE | `/api/admin/products/{id}` | 删除商品 |

商品提交体：

```json
{
  "category_id": 1, "name": "招牌珍珠奶茶", "description": "...", "image": "",
  "price": 18.0, "stock": 0, "unit": "杯", "sort": 1, "status": true,
  "specs": [
    { "id": null, "name": "大杯 少冰", "price": 19.0, "stock": 30, "sort": 1 }
  ]
}
```

> 规格 `id` 传值表示更新已有规格，不传表示新增；未出现在 `specs` 中的既有规格会被删除。

### 订单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/orders?status=&date_from=&date_to=` | 订单列表（最多 500 条）|
| PUT | `/api/admin/orders/{order_no}/status` | `{ "status": 2 }` 改状态 |

## 八、静态页面入口

后端直接托管前端静态资源，无需单独部署：

| 页面 | 地址 | 说明 |
|---|---|---|
| H5 点单页 | `/h5/` | 浏览器 / 支付宝内打开，可直接对外使用 |
| 商家后台 | `/admin/` | 管理商品、库存、订单与统计 |
| 接口文档 | `/docs` | Swagger UI |
| 入口导航 | `/` | 返回上述入口地址的 JSON |

H5 页面采用 hash 路由（`#/menu`、`#/cart`、`#/checkout`、`#/orders`、`#/me`），因此单文件即可承载完整流程，刷新不会 404。
