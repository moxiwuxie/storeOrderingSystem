## 二、后端部署

### 1. 拉取代码并安装依赖

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
vim .env
```

生产环境关键配置：

```ini
DEBUG=false
DATABASE_URL=mysql+pymysql://root:你的密码@127.0.0.1:3306/store_ordering?charset=utf8mb4
JWT_SECRET=请替换为随机长字符串
ADMIN_USERNAME=admin
ADMIN_PASSWORD=请设置强密码

WECHAT_APPID=wx开头的AppID
WECHAT_SECRET=小程序AppSecret
WECHAT_MOCK=false

PAY_MODE=real
WXPAY_MCHID=微信支付商户号
WXPAY_SERIAL_NO=商户证书序列号
WXPAY_API_V3_KEY=APIv3密钥
WXPAY_PRIVATE_KEY_PATH=/opt/certs/apiclient_key.pem
WXPAY_NOTIFY_URL=https://你的域名/api/payment/wechat/notify
ALIPAY_NOTIFY_URL=https://你的域名/api/payment/alipay/notify
```

### 3. 初始化数据库（二选一）

- **方案 A（推荐）**：执行建表脚本，再启动服务自动写入默认管理员与演示数据

  ```bash
  mysql -u root -p < ../sql/mysql_schema.sql
  ```

- **方案 B**：不建库，直接启动服务，由 SQLAlchemy 自动建表

### 4. 启动服务

```bash
# 开发
python run.py

# 生产（多进程）
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

启动后验证：

```bash
curl http://127.0.0.1:8000/api/health
# {"code":0,"msg":"ok","data":{"app":"门店扫码点单系统","pay_mode":"mock"}}
```

### 5. systemd 守护（推荐）

`/etc/systemd/system/store-ordering.service`：

```ini
[Unit]
Description=Store Ordering API
After=network.target mysql.service

[Service]
User=www-data
WorkingDirectory=/opt/storeOrderingSystem/backend
ExecStart=/opt/storeOrderingSystem/backend/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now store-ordering
sudo systemctl status store-ordering
```

### 6. Nginx 反向代理 + HTTPS

微信小程序要求所有请求走 HTTPS，需配置已备案域名与证书。

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate     /etc/nginx/ssl/your-domain.com.pem;
    ssl_certificate_key /etc/nginx/ssl/your-domain.com.key;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

申请免费证书可用 certbot：

```bash
sudo certbot --nginx -d your-domain.com
```

## 四、H5 点单页部署（浏览器 / 支付宝）

H5 点单页由后端直接托管，**无需构建、无需单独部署**：后端启动后访问 `https://your-domain.com/h5/` 即可。它同时承担两个角色：

- **支付宝入口**：顾客用支付宝扫码或直接打开该地址，页面会识别到处于支付宝客户端内，推荐支付宝支付，并可在登录时带上支付宝授权码绑定身份。
- **浏览器入口**：手机 / 电脑浏览器直接打开即可点单，可直接对外使用（例如大堂张贴二维码、公众号菜单链接）。

配置要点：

1. **Nginx 直接透传即可**，第 2 节的 `location /` 已覆盖 `/h5/` 与 `/admin/`，无需额外规则。
2. **HTTPS 必配**：微信 H5 支付、支付宝手机网站支付均要求商户页面为 HTTPS 且域名已备案。
3. **支付授权目录 / 回调域名**：在微信支付商户平台配置 H5 支付域名，在支付宝开放平台配置「手机网站支付」的应用网关与授权回调地址，均指向 `https://your-domain.com`。
4. **环境识别**：页面通过 UA 自动判断 `AlipayClient`（支付宝）与 `MicroMessenger`（微信）以推荐支付方式；若需在支付宝内自动授权，请在支付宝开放平台申请「获取会员信息」能力并把授权链接指向 `/h5/#/me`。
5. **免注册说明**：H5 端以浏览器 `localStorage` 中的设备标识识别顾客，顾客换手机或清缓存后可通过「我的 → 绑定手机号」找回历史订单。

## 六、接入真实支付

代码中 [third_party.py](file:///Users/xiaoxu/Desktop/PycharmProjects/storeOrderingSystem/backend/app/services/third_party.py) 已预留全部接入点，`PAY_MODE=real` 后需补齐。支付按「渠道 × 来源端」分流，共 4 条链路：

| 渠道 | 来源端 | 需补齐的函数 |
|---|---|---|
| 微信 | 小程序 | `create_wechat_pay()` → JSAPI |
| 微信 | H5 | `create_wechat_h5_pay()` → H5 支付 |
| 支付宝 | 小程序 | `create_alipay_pay()` → `orderStr` |
| 支付宝 | H5 | `create_alipay_h5_pay()` → 手机网站支付表单 |

### 微信支付（JSAPI / v3）

1. `create_wechat_pay()`：调用 `POST https://api.mch.weixin.qq.com/v3/pay/transactions/jsapi` 下单，用商户私钥生成请求签名；拿到 `prepay_id` 后按 `appId\ntimeStamp\nnonceStr\npackage\n` 规则生成 `paySign` 返回给小程序。
2. `verify_wechat_notify()`：用微信支付平台证书验签 `Wechatpay-Signature`，再用 APIv3 密钥 AES-256-GCM 解密 `resource`，取出 `out_trade_no` / `trade_state` / `transaction_id`。
3. 回调地址配置为 `WXPAY_NOTIFY_URL`，返回 `{"code":"SUCCESS"}` 表示接收成功。

### 微信 H5 支付（浏览器来源）

1. `create_wechat_h5_pay()`：调用 `POST https://api.mch.weixin.qq.com/v3/pay/transactions/h5` 下单，`scene_info` 必传 `h5_info.type = "Wap"`（浏览器）/`"iOS"`/`"Android"`；返回体中的 `h5_url` 即前端跳转支付地址。
2. 需在微信支付商户平台开通 **H5 支付** 产品并配置支付域名。
3. 支付完成后微信会回跳 `h5_url` 中携带的 `redirect_url`，请把跳转结果页指向 `/h5/#/result?order_no=xxx`。

### 支付宝手机网站支付（H5 来源）

1. `create_alipay_h5_pay()`：调用 `alipay.trade.wap.pay`，用应用私钥对参数做 RSA2 签名，生成自动提交的 `<form>` HTML 返回（本项目已按此形态返回 `form_html`），前端注入即跳转支付宝收银台。
2. 需在支付宝开放平台为应用签约 **手机网站支付** 产品。
3. 同步回跳地址 `return_url` 指向 `/h5/#/result?order_no=xxx`。

### 支付宝小程序支付（orderStr）

1. `create_alipay_pay()`：使用应用私钥对 `alipay.trade.create` 参数签名，返回 `orderStr` 供小程序端 `my.tradePay` 拉起。

### 回调验签

- `verify_alipay_notify()`：用支付宝公钥对回调参数做 RSA2 验签，校验 `trade_status` 为 `TRADE_SUCCESS`。
- 手机网站支付与小程序支付共用同一套 `alipay/notify` 回调，逻辑一致。

### 登录

- 微信：`WECHAT_MOCK=false` 后自动走 `jscode2session`，无需改代码。
- 支付宝：`alipay_auth2user()` 需补齐 `alipay.system.oauth.token` 的签名调用；H5 端在支付宝内打开时把 `auth_code` 传给 `/api/auth/h5` 即可自动绑定。

## 八、常见问题

| 现象 | 排查 |
|---|---|
| 小程序提示「网络异常」 | 后端未启动 / baseUrl 填错 / 未勾选「不校验合法域名」|
| 真机无法访问 | baseUrl 用了 `127.0.0.1`，需改成电脑局域网 IP，且手机与电脑同网段 |
| 登录失败 | 检查 `WECHAT_APPID` / `WECHAT_SECRET`，或本地保持 `WECHAT_MOCK=true` |
| H5 打开后一直在加载 | 确认访问的是 `/h5/`（带斜杠）；浏览器控制台看 `/api/auth/h5` 是否 200 |
| H5 换手机后看不到历史订单 | 属预期：设备标识变了，在「我的」绑定手机号即可找回 |
| 支付后订单仍为待支付 | `PAY_MODE=mock` 只能在本地用；线上需确保回调地址可达且验签逻辑正确 |
| H5 支付跳转后未回跳结果页 | 检查微信 H5 支付 `redirect_url` / 支付宝 `return_url` 是否指向 `/h5/#/result?order_no=xxx` |
| 库存扣减异常 | 确认下单事务未被打断；高并发场景参考《数据库设计》中的悲观锁方案 |
| 启动报 `NOT NULL constraint failed: xxx.id` | 主键在 SQLite 下未用 `BigIntType` 变体，参考《数据库设计》中的方言兼容说明 |
